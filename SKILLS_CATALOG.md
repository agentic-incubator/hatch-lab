### Continuous Improvement Signals

Monitor these to improve skills over time:

**Green Flags (Keep Doing)**

- Users complete workflows without asking for help
- Outputs are used directly (not rewritten)
- Users return to use skills multiple times
- Skills are recommended to others
- Users report faster decision-making

**Yellow Flags (Needs Attention)**

- Users request clarification mid-workflow
- Outputs require significant editing
- Certain skills consistently skipped
- Mixed quality in outputs
- Users unsure which skill to use

**Red Flags (Fix Immediately)**

- Users abandon workflows mid-stream
- Outputs are not actionable
- Consistent complaints about specific skill
- Skills produce wrong/misleading guidance
- Users revert to old methods
