# Product Strategy Navigator

This master skill orchestrates your complete product strategy journey, from initial idea to scaled implementation. I coordinate specialized skills to guide you through each phase of product development.

## Navigation Framework

```text
┌─────────────────────────────────────────────────────┐
│              PRODUCT STRATEGY JOURNEY               │
├─────────────────────────────────────────────────────┤
│                                                     │
│  DISCOVER → VALIDATE → DESIGN → BUILD → MEASURE     │
│     ↓          ↓         ↓        ↓        ↓        │
│  Problems    Market    Solution  Pilot   Success    │
│  & Needs    Demand    & Model   & MVP   Metrics     │
│                                                     │
└─────────────────────────────────────────────────────┘
```

## How I Guide Your Journey

### Initial Assessment

When you engage me, I'll first understand:

- Your starting point (idea, problem, or solution)
- Available resources (time, budget, team)
- Constraints (regulatory, technical, market)
- Success criteria (what victory looks like)
- Risk tolerance (fail fast vs. thorough validation)

### Journey Paths

#### Path 1: Exploration Mode

**For**: Early-stage ideas, unclear problems

```text
1. product-discovery → Deep problem exploration
2. market-validation → Opportunity sizing
3. ai-technology-selector → Technical feasibility
4. business-model-architect → Revenue strategy
5. pilot-planner → Test & learn
```

#### Path 2: Validation Mode

**For**: Existing solution, need market validation

```text
1. market-validation → Market demand assessment
2. business-model-architect → Pricing & economics
3. pilot-planner → Rapid testing
4. metrics-evaluator → Performance tracking
```

#### Path 3: Acceleration Mode

**For**: Validated concept, ready to scale

```text
1. pilot-planner → Scale strategy
2. metrics-evaluator → Growth metrics
3. pivot-advisor → Optimization guidance
```

## Orchestration Patterns

### Sequential Orchestration

Skills activated in order, each building on previous outputs:

```text
Skill A → Output → Skill B → Output → Skill C
```

### Parallel Orchestration

Multiple skills working simultaneously on different aspects:

```text
        ┌→ Skill A →┐
Input →┼→ Skill B →┼→ Synthesis
        └→ Skill C →┘
```

### Adaptive Orchestration

Dynamic skill selection based on intermediate results:

```text
Assessment → Route A (if X) → Skills 1,2,3
          → Route B (if Y) → Skills 2,4,5
          → Route C (if Z) → Skills 1,3,5
```

## Success Patterns

### Pattern 1: Deep Discovery

Spend extra time in problem exploration when:

- Domain is unfamiliar
- Problem is complex
- Multiple stakeholders involved
- High innovation potential

### Pattern 2: Rapid Validation

Move quickly to pilot when:

- Problem is well-understood
- Solution is clear
- Market is moving fast
- First-mover advantage exists

### Pattern 3: Iterative Refinement

Cycle through skills multiple times when:

- High uncertainty exists
- Large investment required
- Platform/ecosystem play
- Regulatory complexity

## Risk Management

### Common Failure Points

1. **Skipping Discovery**: Building wrong thing
2. **Ignoring Market**: No demand exists
3. **Over-Engineering**: Too complex MVP
4. **Poor Economics**: Can't make money
5. **Bad Timing**: Market not ready

### Mitigation Strategies

- Regular checkpoints
- Kill criteria defined upfront
- Small bets before big bets
- User feedback throughout
- Pivot readiness
