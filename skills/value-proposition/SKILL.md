### Step 2: Value Proposition Formulation

#### Classic Formula Templates

**Geoffrey Moore's Template**:

```
For [target customer]
Who [statement of need/opportunity]
Our [product name] is [product category]
That [key benefit/reason to buy]
Unlike [primary competitive alternative]
Our product [primary differentiation]
```

**Steve Blank's XYZ Formula**:

```
We help X do Y by doing Z
```

**Value Proposition Statement**:

```
[Product] enables [customer] to [job to be done]
by [unique approach] unlike [alternative]
resulting in [key outcome]
```

#### Benefit Ladder

```
FEATURES → FUNCTIONAL BENEFITS → EMOTIONAL BENEFITS → VALUES
    ↓              ↓                    ↓                ↓
What it is    What it does       How it feels    What it means

Example:
Fast processor → Saves time → Less stress → More family time
```

### Step 4: Benefit Articulation

#### Features vs Benefits Translation

```
FEATURE: What it is
    ↓
ADVANTAGE: What it does
    ↓
BENEFIT: What it means for customer
    ↓
VALUE: Worth to customer

Example:
256-bit encryption → Secures data → Peace of mind → Protect reputation
```

### Step 5: Message Development

#### Messaging Hierarchy

```
TAGLINE (3-7 words)
    ↓
ELEVATOR PITCH (30 seconds)
    ↓
VALUE PROPOSITION (1-2 sentences)
    ↓
KEY MESSAGES (3-5 points)
    ↓
PROOF POINTS (Evidence)
    ↓
DETAILED BENEFITS (Full story)
```

#### Message Testing Criteria

**Clarity Test**:

- Can a 12-year-old understand it?
- Single main idea?
- Jargon-free?

**Relevance Test**:

- Addresses real pain?
- Customer language?
- Timely need?

**Differentiation Test**:

- Only we can claim?
- Memorable?
- Defensible?

**Credibility Test**:

- Believable?
- Provable?
- Supported by evidence?

## Common Value Prop Mistakes

⚠️ **Feature Focus**: Listing what not why
⚠️ **Too Generic**: Could be anyone
⚠️ **Unbelievable**: Over-promising
⚠️ **Complex**: Too much to absorb
⚠️ **Inside-Out**: Company not customer view
