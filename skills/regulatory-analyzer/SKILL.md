# Regulatory Analyzer Skill

This skill helps you navigate complex regulatory landscapes, ensure compliance, and build governance frameworks that protect
your business while enabling innovation. We'll identify requirements, assess risks, and create actionable compliance strategies.

## Core Capabilities

I can help you:

- Identify applicable regulations and standards
- Assess compliance requirements and gaps
- Design privacy and data protection strategies
- Create governance frameworks
- Evaluate regulatory risks
- Plan compliance implementations
- Prepare for audits and certifications
- Navigate AI and emerging tech regulations

#### GDPR Compliance Checklist

```
LEGAL BASIS
├─ Consent (freely given, specific)
├─ Contract (necessary for performance)
├─ Legal Obligation (required by law)
├─ Vital Interests (life or death)
├─ Public Task (official authority)
└─ Legitimate Interests (balanced)

DATA SUBJECT RIGHTS
├─ Access (provide copy)
├─ Rectification (correct errors)
├─ Erasure (right to delete)
├─ Portability (machine-readable)
├─ Object (stop processing)
├─ Restrict (limit processing)
└─ Automated Decision (human review)

ORGANIZATIONAL MEASURES
├─ Privacy Policy (clear, accessible)
├─ Data Protection Officer (if required)
├─ Records of Processing (Article 30)
├─ Data Protection Impact Assessment
├─ Breach Notification (72 hours)
└─ Vendor Management (processors)
```

## Example Compliance Analysis

**Product**: B2B SaaS Processing EU Data

```markdown
### Regulatory Requirements

1. **GDPR**: EU personal data processing
2. **SOC 2 Type II**: Enterprise customers
3. **ISO 27001**: Security certification
4. **CCPA**: California residents

### Compliance Priorities

| Requirement | Priority | Timeline  | Cost  |
| ----------- | -------- | --------- | ----- |
| GDPR DPA    | Critical | Q1        | $50K  |
| SOC 2       | High     | Q2-Q3     | $75K  |
| ISO 27001   | Medium   | Q4        | $100K |
| CCPA        | Low      | Next Year | $25K  |

### Key Actions

1. Appoint DPO or privacy lead
2. Implement consent management
3. Create data processing agreements
4. Develop incident response plan
5. Conduct privacy impact assessment

### Risk Mitigation

- Data Breach: Encryption + monitoring
- Access Control: MFA + RBAC
- Vendor Risk: Due diligence + contracts
- Cross-border: SCCs + data localization
```
