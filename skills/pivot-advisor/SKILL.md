# Pivot Advisor Skill

This skill helps you recognize when to pivot, evaluate strategic alternatives, and execute transitions effectively. Using
proven frameworks, we'll guide you through strategic changes while preserving what's working and fixing what isn't.

## Core Capabilities

I can help you:

- Identify pivot triggers and warning signs
- Evaluate different pivot strategies
- Assess pivot risks and opportunities
- Plan transition roadmaps
- Manage stakeholder communications
- Preserve valuable assets during change
- Minimize disruption and maintain momentum
- Learn from pivot experiences

## Pivot Decision Framework

### Step 1: Pivot Signal Detection

#### Early Warning Indicators

```
MARKET SIGNALS
├─ Declining growth rate
├─ Rising CAC
├─ Competitive pressure
├─ Market shift
└─ Regulatory change

PRODUCT SIGNALS
├─ Low engagement
├─ Poor retention
├─ Feature abandonment
├─ Technical debt
└─ Scaling issues

BUSINESS SIGNALS
├─ Unit economics breakdown
├─ Funding challenges
├─ Team morale issues
├─ Customer complaints
└─ Partner problems
```

#### Pivot Trigger Matrix

```
         Low Impact    High Impact
         on Business   on Business
         ↑             ↑
High    │  Monitor    │  URGENT
Problem │  Closely    │  PIVOT
Severity│             │  NEEDED
        ├─────────────┼───────────┤
Low     │  Track      │  Plan
Problem │  Trends     │  Pivot
Severity│             │  Timeline
        ↓             ↓
```

#### Data-Driven Triggers

**Quantitative Thresholds**:

- Growth rate < 10% MoM for 3 months
- CAC:LTV ratio > 1:1
- Churn > 10% monthly
- NPS < 0
- Runway < 6 months

**Qualitative Signals**:

- Consistent customer feedback themes
- Team losing confidence
- Investors expressing concerns
- Market assumptions proven wrong
- Technology limitations discovered

### Step 2: Pivot Options Evaluation

#### Types of Pivots

**1. Zoom-in Pivot**

```
Single Feature → Whole Product
Example: Burbn photo feature → Instagram
```

**2. Zoom-out Pivot**

```
Whole Product → Single Feature
Example: Full suite → Core functionality
```

**3. Customer Segment Pivot**

```
Current Market → New Market
Example: Consumers → Enterprise
```

**4. Customer Need Pivot**

```
Problem A → Problem B
Example: Video chat → Video messaging
```

**5. Platform Pivot**

```
Application → Platform (or reverse)
Example: Product → Marketplace
```

**6. Architecture Pivot**

```
High Margin/Low Volume ↔ Low Margin/High Volume
Example: Custom solutions → SaaS
```

**7. Value Capture Pivot**

```
Revenue Model A → Revenue Model B
Example: Subscription → Transaction fee
```

**8. Engine of Growth Pivot**

```
Viral → Paid → Sticky (or combinations)
Example: Organic growth → Sales-driven
```

**9. Channel Pivot**

```
Distribution A → Distribution B
Example: Direct sales → Partnership
```

**10. Technology Pivot**

```
Technology A → Technology B
Example: Native app → Web platform
```

### Step 4: Transition Planning

```

├─ Finalize pivot decision
├─ Develop transition plan
├─ Prepare communications
├─ Identify quick wins
└─ Set success metrics

PHASE 2: COMMUNICATION (Week 3)
├─ Team alignment
├─ Customer notification
├─ Investor update

├─ Stop: Sunset old features

└─ Measure: Track progress

PHASE 4: VALIDATION (Week 13-16)
├─ Assess metrics
├─ Gather feedback
├─ Adjust strategy
├─ Scale or iterate
└─ Document learnings
```

## Pivot Case Studies

### Example 1: B2B SaaS Platform Pivot

**Situation**: Project management tool with low retention

**Analysis**:

```markdown
### Signals

- 60% churn in month 2
- Users only using 1 feature (time tracking)
- CAC $500, LTV $300

### Pivot Decision

Type: Zoom-in Pivot
Direction: Full platform → Time tracking specialist

### Execution

- Week 1-2: Refined time tracking features
- Week 3: Communicated to 500 customers
- Week 4-8: Rebuilt onboarding
- Week 9-12: New pricing model

### Results

- Retention improved to 85%
- CAC dropped to $200
- LTV increased to $1,200
```

### Example 2: Consumer App Pivot

**Situation**: Social shopping app with no traction

**Analysis**:

```markdown
### Signals

- 50K downloads, <1% DAU
- High engagement in wish list feature
- Users not completing purchases

### Pivot Decision

Type: Customer Need Pivot
Direction: Shopping → Price tracking/alerts

### Execution

- Preserved: Wish list functionality
- Added: Price monitoring, alerts
- Removed: Social features, checkout

### Results

- DAU increased to 15%
- Monetization via affiliate fees
- Acquired by major retailer
```

## Pivot Success Factors

### Critical Success Elements

✓ **Speed**: Move fast once decided
✓ **Clarity**: Clear communication to all
✓ **Focus**: Do fewer things better
✓ **Data**: Measure everything
✓ **Iteration**: Continuous adjustment

### Common Pivot Mistakes

✗ **Too Late**: Waiting until crisis
✗ **Too Radical**: Abandoning all assets
✗ **Poor Communication**: Surprising stakeholders
✗ **No Validation**: Pivoting to another guess
✗ **Pivot Addiction**: Constant direction changes
