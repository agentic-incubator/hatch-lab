decisions. Using proven research methodologies, we'll uncover what your customers truly need and want.

#### Research Methods Selection

**Qualitative Methods**

- **User Interviews**: Deep 1:1 conversations
- **Focus Groups**: Group dynamics and reactions
- **Ethnographic Studies**: Observing natural behavior
- **Diary Studies**: Longitudinal behavior tracking
- **Card Sorting**: Mental model understanding
- **Usability Testing**: Solution validation

**Quantitative Methods**

- **Surveys**: Scale insights across populations
- **A/B Testing**: Statistical comparison
- **Analytics**: Behavioral data analysis
- **Conjoint Analysis**: Feature preference ranking
- **Net Promoter Score**: Satisfaction measurement
- **Cohort Analysis**: Segment behavior patterns

#### Sample Size Guidelines

- **Interviews**: 5-8 per segment (saturation)
- **Usability Tests**: 5 users find 85% of issues
- **Surveys**: 30+ for statistics, 385 for 95% confidence
- **Focus Groups**: 6-10 per group, 3-4 groups
- **A/B Tests**: Calculate based on effect size

#### Effective Question Types

**Open-Ended Questions**

- "Tell me about..."
- "Walk me through..."
- "What's your experience with..."

**Probing Questions**

- "Why is that important?"
- "Can you give an example?"
- "What happens next?"

**Laddering Technique**

```
Feature → Benefit → Value
"What?" → "So what?" → "Why does it matter?"
```

## Advanced Research Techniques

### Jobs-to-be-Done Interviews

Focus on:

- Situation (context)
- Motivation (push/pull)
- Outcome (desired result)
- Barriers (anxieties)

### Kano Model Analysis

Categorize features as:

- **Basic**: Expected, dissatisfiers if missing
- **Performance**: Linear satisfaction
- **Delighters**: Unexpected joy
- **Indifferent**: No impact
- **Reverse**: Some prefer absence

### Contextual Inquiry

- Observe users in natural environment
- Master-apprentice model
- Think-aloud protocol
- Artifact collection

## Research Quality Checklist

### Validity Checks

✓ **Representative Sample**: Matches target market
✓ **Sufficient Size**: Statistical significance
✓ **Unbiased Questions**: Neutral framing
✓ **Mixed Methods**: Triangulation
✓ **Recent Data**: Current behaviors

### Common Biases to Avoid

⚠️ **Confirmation Bias**: Seeking supporting data
⚠️ **Selection Bias**: Non-representative sample
⚠️ **Response Bias**: Leading questions
⚠️ **Survivorship Bias**: Only studying successes
⚠️ **Recency Bias**: Overweighting recent events
