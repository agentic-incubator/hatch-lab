# HCI Designer Skill

This skill helps you design intuitive, accessible, and delightful user interfaces and experiences. Using proven HCI
principles and UX methodologies, we'll create products that users love and can easily use.

## Core Capabilities

I can help you:

- Design user interfaces and interactions
- Create user flows and wireframes
- Apply usability heuristics and principles
- Ensure accessibility and inclusivity
- Design information architecture
- Create design systems and patterns
- Conduct usability testing
- Optimize user experience metrics

### Step 3: Interaction Design

#### Interaction Principles

**Feedback Mechanisms**

```
USER ACTION → SYSTEM RESPONSE
├─ Immediate (< 0.1s): Feels instant
├─ Quick (< 1s): Maintains flow
├─ Loading (1-10s): Progress indicator
└─ Long (> 10s): Allow cancellation
```

**Affordances & Signifiers**

```
AFFORDANCE: What's possible
SIGNIFIER: How to do it

Button → Clickable (shadow, hover)
Slider → Draggable (handle, track)
Text Field → Editable (cursor, border)
Link → Navigable (underline, color)
```

**Interaction Patterns**

- **Direct Manipulation**: Drag, pinch, swipe
- **Form Patterns**: Inline validation, smart defaults
- **Navigation Patterns**: Tabs, accordion, carousel
- **Feedback Patterns**: Toast, modal, inline message
- **Data Input**: Autocomplete, picker, stepper

### Step 4: Visual Design

#### Visual Hierarchy

```
EMPHASIS TECHNIQUES
├─ Size (larger = important)
├─ Color (contrast = attention)
├─ Space (isolation = focus)
├─ Typography (bold = emphasis)
├─ Position (top-left = primary)
└─ Motion (animation = notice)
```

#### Gestalt Principles

```
PROXIMITY: Related items together
SIMILARITY: Like items look alike
CLOSURE: Mind completes shapes
CONTINUITY: Eye follows lines
FIGURE/GROUND: Focus vs background
COMMON FATE: Moving together = group
```

#### Color Theory Application

```
COLOR PURPOSES
├─ Brand (identity)
├─ Emotion (mood)
├─ Function (meaning)
├─ Hierarchy (importance)
├─ State (status)
└─ Accessibility (contrast)

COLOR SYSTEM
├─ Primary (main actions)
├─ Secondary (supporting)
├─ Semantic (success/error)
├─ Neutral (text/backgrounds)
└─ Accent (highlights)
```

### Step 5: Usability Heuristics

#### Nielsen's 10 Heuristics

1. **Visibility of System Status**
   - Progress indicators
   - Loading states
   - Current location

2. **Match System & Real World**
   - User's language
   - Natural mappings
   - Familiar concepts

3. **User Control & Freedom**
   - Undo/redo
   - Clear exits
   - Cancel options

4. **Consistency & Standards**
   - Platform conventions
   - Internal consistency
   - Predictable behavior

5. **Error Prevention**
   - Confirmation dialogs
   - Constraints
   - Smart defaults

6. **Recognition Over Recall**
   - Visible options
   - Contextual help
   - Clear labels

7. **Flexibility & Efficiency**
   - Shortcuts
   - Customization
   - Expert paths

8. **Aesthetic & Minimalist**
   - Essential info only
   - Progressive disclosure
   - Clean design

9. **Error Recovery**
   - Clear error messages
   - Solution suggestions
   - Graceful degradation

10. **Help & Documentation**
    - Contextual help
    - Search function
    - Task-oriented

### Step 6: Accessibility Design

#### WCAG 2.1 Principles

```
PERCEIVABLE
├─ Alt text for images
├─ Captions for videos
├─ Color not sole indicator
└─ Sufficient contrast (4.5:1)

OPERABLE
├─ Keyboard navigable
├─ No seizure triggers
├─ Sufficient time limits
└─ Clear navigation

UNDERSTANDABLE
├─ Readable text
├─ Predictable functionality
├─ Input assistance
└─ Error identification

ROBUST
├─ Valid markup
├─ ARIA landmarks
├─ Screen reader compatible
└─ Cross-browser support
```

#### Inclusive Design Patterns

```
PERMANENT → Blind users
TEMPORARY → Broken arm
SITUATIONAL → Bright sunlight

SOLUTIONS
├─ Multiple modalities
├─ Flexible interfaces
├─ Clear communication
├─ Error tolerance
└─ User preferences
```

## Example HCI Design Output

**Product**: Mobile Banking App

**Design Solution**:

```markdown
### User Research Insights

- Users anxious about security
- Need quick balance checks
- Want spending insights
- Require easy bill payment

### Design Decisions

1. **Biometric Login**: Reduce friction + security

3. **Gesture Navigation**: Swipe between accounts
4. **Visual Spending**: Charts over tables
5. **One-Tap Actions**: Common tasks prominent

### Accessibility Features

- High contrast mode
- Large touch targets (44px min)
- Screen reader optimized
- Voice control support
- Customizable text size

### Usability Test Results

- Task success: 92%
- Average time: 45 seconds
- SUS score: 82 (excellent)
- Key issue: Transfer flow confusion
- Iteration: Simplified transfer steps
```

## Common Design Mistakes

⚠️ **Aesthetic Over Function**: Pretty but unusable
⚠️ **Feature Creep**: Too many options
⚠️ **Ignoring Standards**: Reinventing patterns
⚠️ **Poor Contrast**: Accessibility issues
⚠️ **No User Testing**: Assuming vs validating
